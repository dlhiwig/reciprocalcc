Security and compliance programs

Security and compliance programs represented on the site badge: AICPA SOC examination language (not “SOC certified”), ISO/IEC 27001 information security management, GDPR alignment, and HIPAA compliance program alignment. Ask for the examined entity, covered system, report type, and period for any SOC report relevant to an engagement.

  • SOC: SOC examination available on request for the examined entity and covered system. Use Type I or Type II language from the report; do not describe SOC as a certification.
  • ISO/IEC 27001: ISO/IEC 27001 information security management certification, as represented on the site badge. Request the certificate scope and validity for engagement-specific use.
  • GDPR: GDPR alignment for applicable personal data processing. Not a certification.
  • HIPAA: HIPAA compliance program alignment for applicable protected health information workflows. Not a certification.

Entity identifiers such as UEI and CAGE, certificate numbers, and audit periods are provided on request for the proposed contracting party and are not published as placeholders on this site.
